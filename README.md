# labeling-helper

CSV 파일을 불러와 행 단위로 데이터를 확인하고 라벨링 결과를 기록하는 웹 도구입니다.

긴 텍스트, URL, 이미지 URL이 포함된 CSV 데이터를 빠르게 검토하면서 `0`, `1`, `보류` 같은 라벨을 붙이고, 결과를 다시 CSV 파일로 저장할 수 있습니다.

## 사용 방법

1. `index.html`을 브라우저에서 엽니다.
2. CSV 파일을 선택합니다. 첫 번째 행은 헤더로 사용됩니다.
3. 확인할 칼럼을 선택합니다.
   - 라벨링 화면에서 보여줄 칼럼입니다.
   - 빈 값인 칼럼은 라벨링 화면에서 표시되지 않습니다.
4. 결과 기록 칼럼을 선택합니다.
   - 라벨링 결과가 저장될 칼럼입니다.
   - 새 결과 칼럼을 만들 수도 있습니다.
5. 다시 라벨링할 결과값을 선택합니다.
   - 예: `빈칸`을 선택하면 아직 라벨링되지 않은 행만 불러옵니다.
   - 예: `보류`를 선택하면 기존 결과가 `보류`인 행만 다시 검토합니다.
6. 라벨 값을 설정합니다.
   - 기본값은 `0`, `1`, `보류`입니다.
   - 필요한 라벨을 추가하거나 삭제할 수 있습니다.
7. `라벨링 시작하기`를 누릅니다.
8. 행 내용을 확인하고 하단의 라벨 버튼을 선택합니다.
9. 작업이 끝나면 `결과 CSV 다운로드`로 라벨링된 CSV 파일을 저장합니다.

## GitHub Pages로 배포하기

이 프로젝트는 별도 빌드가 필요 없는 정적 웹앱입니다. GitHub Pages를 켜면 휴대폰에서도 URL로 접속할 수 있습니다.

1. 변경사항을 `main` 브랜치에 push합니다.
2. GitHub 저장소에서 `Settings` > `Pages`로 이동합니다.
3. `Build and deployment`의 `Source`를 `GitHub Actions`로 선택합니다.
4. `Actions` 탭에서 `Deploy GitHub Pages` 워크플로가 성공할 때까지 기다립니다.
5. 배포가 끝나면 `Settings` > `Pages`에 표시되는 URL로 접속합니다.

배포 URL 예시:

```text
https://사용자명.github.io/저장소명/
```

휴대폰에서는 위 URL을 브라우저에서 열고 CSV 파일을 선택하면 됩니다.

## 주요 기능

- CSV 파일 업로드
- 단계별 설정 화면
- 여러 확인 칼럼 선택
- 결과 기록 칼럼 선택 또는 새 칼럼 생성
- 특정 결과값만 다시 라벨링
- URL 칼럼 자동 감지
- URL이 여러 개 있으면 탭으로 전환
- 이미지 URL은 전체 이미지가 보이도록 표시
- 새 탭에서 URL 확인
- 진행 상황 자동 저장
- 직전 데이터 불러오기
- 결과 CSV 다운로드

## 진행 상황 저장

작업 중 브라우저를 닫거나 새로고침해도 진행 상황이 브라우저의 `localStorage`에 자동 저장됩니다.

다시 페이지를 열면 `직전 데이터 불러오기` 버튼이 표시되며, 누르면 이전 작업을 이어서 진행할 수 있습니다.

## 주의사항

- CSV의 첫 번째 행은 반드시 헤더여야 합니다.
- 헤더 이름이 비어 있는 칼럼은 불러오지 않습니다.
- URL 미리보기는 일부 사이트의 보안 정책 때문에 보이지 않을 수 있습니다. 이 경우 `새 탭에서 확인하기`를 사용하세요.
- 매우 큰 CSV 파일은 브라우저 저장 용량 제한 때문에 자동 저장이 실패할 수 있습니다.
- 현재 UI는 데스크톱 사용에 가장 적합합니다.
